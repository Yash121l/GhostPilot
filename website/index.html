How it works

From draft to published
in four steps.

1
Connect your accounts
OAuth flows open in your browser. Tokens are stored in the macOS Keychain — GhostPilot never sees your password and tokens never leave your machine.
2
Add an AI provider key
Paste your OpenAI, Anthropic, Groq, or OpenRouter key in Settings. Or point it at a local Ollama instance — no key needed.
3
Write your draft & generate variants
Type your raw idea in the Composer. Hit Generate — AI produces platform-native variants for each selected network simultaneously.
4
Approve, schedule, done
Review each variant, pick a date and time, and confirm. A background worker thread publishes at the scheduled moment — even if the window is hidden.

Privacy & Security

Your data stays
on your machine.

GhostPilot was designed from day one to never require a server, an account, or trust in a third party.

🔐 OS Keychain storage
OAuth tokens and API keys are stored exclusively in the macOS Keychain. They are never written to the database or sent to any server.
🗄️ Local SQLite database
All posts, personas, goals, and analytics live in a single SQLite file on your Mac. You own it, you can back it up, you can delete it.
🚫 No telemetry
Zero analytics, zero crash reporting, zero usage tracking. The app makes no outbound requests except to the platforms you explicitly connect.
🔓 Open source
Every line of code is on GitHub. Audit it, fork it, build on it. No hidden behaviour, no obfuscated binaries.
📋 Append-only audit log
Every sensitive action is recorded locally in an immutable audit log. You can query it any time from the app.
💸 BYOK — no markup
AI calls go directly from your machine to the provider. You pay the provider's rate — GhostPilot takes no cut and sees no content.
FAQ

Common questions

What is GhostPilot?

GhostPilot is a free, open-source desktop app that uses AI to adapt a single draft into platform-native posts for LinkedIn, X (Twitter), and Instagram simultaneously. It runs entirely on your machine — no cloud account, no subscription, no data leaving your device.

Is GhostPilot free?

Yes. GhostPilot itself is free and open-source (MIT license). You only pay for your own AI API usage, which goes directly to the provider (OpenAI, Anthropic, etc.) at their standard rates. GhostPilot takes no cut and never sees your content.

Which AI providers are supported?

GhostPilot supports OpenAI (GPT-4o), Anthropic (Claude), Groq (Llama 3), OpenRouter, and local Ollama models. You paste your own API key in Settings — it is stored in the OS keychain (macOS Keychain, Windows Credential Store, Linux Secret Service) and never uploaded anywhere.

Which platforms does GhostPilot support?

Social platforms: LinkedIn, X (Twitter), Instagram. Operating systems: macOS 13+ (Apple Silicon & Intel), Windows 10/11 (x64), Linux x64. ARM64 Windows is not yet supported.

Does GhostPilot send my data to the cloud?

No. All posts, personas, goals, and analytics are stored in a local SQLite file. OAuth tokens and API keys live in the OS keychain. The only outbound requests are to the social platforms you connect and to the AI provider whose key you supply — GhostPilot itself has no server.

How does post scheduling work?

GhostPilot runs a background worker thread that checks for due posts every minute using node-cron. When a scheduled time arrives, the worker dispatches the post to the platform API and records the result. Up to 3 retry attempts are made on transient failures before the post is marked as permanently failed. The app must be running for scheduled posts to publish.
